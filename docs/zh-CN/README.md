# omnix 使用文档

[English](../en/README.md) · [项目介绍](../../README.zh-CN.md)

omnix 是在 Go 进程内运行的 Agent SDK，以事件日志组织执行状态。应用负责提供模型适配器、工具、持久化和执行策略。建议先通过离线示例了解生命周期，再接入模型服务。

## 开始使用

使用 Go 1.25 或更新版本，版本要求见 [go.mod](../../go.mod)。在已有 Go 模块中添加 SDK：

```sh
go get github.com/herlanai/omnix
```

本地开发时，在仓库根目录运行：

```sh
go run ./examples/agent_loop
```

这个示例使用本地适配器，不需要 API Key。[Agent 指南](agent.md) 提供完整离线程序，说明如何从事件日志读取执行结果。接着可以通过[工具指南](tools.md) 注册工具并使用执行流水线调用。

## 结合源码阅读

[示例目录](../../examples) 展示集成方式，[包源码](../../pkg) 定义公开行为，[测试目录](../../tests) 覆盖跨包场景。各篇文档都链接到对应实现。压缩、审批、持久化和遥测等组件需要由应用显式接入，仓库中存在某个组件并不代表每个 Agent 都会自动启用它。

中英文目录使用相同文件名，每篇文档都可直接切换语言。公开 API 或文档描述的行为变化时，请同步修改两种语言，并基于同一版本验证可运行示例。
